দ্বীনিয়াত মক্তব ম্যানেজার — প্রাথমিক Android-friendly offline web app

শুরু:
1) ZIP ফাইলটি Extract করুন।
2) index.html Android Chrome-এ খুলুন (লোকাল ফাইল হিসেবে কিছু ফোনে PWA/Service Worker কাজ নাও করতে পারে)।
3) ভালোভাবে ইনস্টলযোগ্য অফলাইন অ্যাপ করতে ফাইলগুলো HTTPS ওয়েব হোস্টিংয়ে প্রকাশ করে Chrome > Add to Home screen ব্যবহার করুন।
4) ডেটা এই ডিভাইসের ব্রাউজারে থাকে। নিয়মিত Backup ডাউনলোড করুন।

বর্তমান ফিচার:
- একাধিক মক্তব যোগ/নির্বাচন
- আয়, ব্যয় ও জমা এন্ট্রি
- শিক্ষার্থী তালিকা ও মাসিক বেতন তথ্য
- বই বিক্রি এবং বিক্রির আয়
- সারসংক্ষেপ ও CSV রিপোর্ট
- JSON ব্যাকআপ/রিস্টোর
- অফলাইন ক্যাশিংয়ের প্রাথমিক Service Worker

গুরুত্বপূর্ণ সীমাবদ্ধতা:
- এটি প্রাথমিক প্রোটোটাইপ; native APK নয়।
- স্বয়ংক্রিয় অনলাইন ক্লাউড সিঙ্ক, লগইন/পাসওয়ার্ড, ব্যবহারকারী অনুমতি, সার্ভার-সাইড ব্যাকআপ এখনো যুক্ত হয়নি।
- ডেটা মোবাইলের ব্রাউজার স্টোরেজে থাকে; ব্রাউজারের ডেটা মুছে ফেললে হারাতে পারে। ব্যাকআপ রাখুন।
- বাস্তব ব্যবহারের আগে নিরাপত্তা, মাসিক বকেয়া গণনা, হিসাব মিলানো এবং Excel আমদানি যাচাই প্রয়োজন।

দ্বীনিয়াত মক্তব ম্যানেজার — Android APK Build Project

এই ZIP-এ Android Studio / GitHub Actions দিয়ে APK তৈরির Android প্রজেক্ট রয়েছে।

অন্তর্ভুক্ত ফিচার:
১. মক্তবের নাম ও পরিচালকের তথ্য সংরক্ষণ
২. শিক্ষার্থী যোগ, সম্পাদনা, খোঁজা ও মুছে ফেলা
৩. শিক্ষার্থীর মাসিক বেতন নির্ধারণ এবং বেতন আদায়ের একাধিক কিস্তির রেকর্ড
৪. আদায়কৃত মাসিক বেতনের ৫০% শিক্ষক কমিশনের হিসাব (বই বিক্রি/অনুদান/অন্য আয়ে কমিশন নেই)
৫. শিক্ষক যোগ, সম্পাদনা ও তালিকা
৬. দৈনিক ছাত্র-ছাত্রীর উপস্থিতি সংরক্ষণ
৭. অন্যান্য আয় ও ব্যয়ের খতিয়ান
৮. মাসিক সারাংশ ও CSV রিপোর্ট (Excel-এ খোলা যাবে)
৯. JSON ব্যাকআপ ডাউনলোড এবং ব্যাকআপ থেকে ডেটা পুনরুদ্ধার
১০. অফলাইনে ফোনের লোকাল স্টোরেজে ডেটা সংরক্ষণ

গুরুত্বপূর্ণ সীমাবদ্ধতা:
- এই সংস্করণে ডেটা ফোনের লোকাল স্টোরেজে থাকে। Google Drive-এ স্বয়ংক্রিয় ব্যাকআপ/সিঙ্ক এখনো যুক্ত নয়।
- শিক্ষক কমিশন রিপোর্টে আদায়কৃত বেতনের ৫০% হিসেবে গণনা হয়; প্রকৃত পরিশোধের জন্য আয়-ব্যয় অংশে “শিক্ষক কমিশন পরিশোধ” ব্যয় হিসেবে এন্ট্রি করতে হবে।
- এই ZIP হলো সোর্স প্রজেক্ট; APK ফাইল নয়। এখানে APK বিল্ড চালিয়ে পরীক্ষা করা হয়নি।

APK তৈরির নিয়ম:
১. ZIP Extract করুন।
২. ভেতরের DiniyatMaktabAndroid ফোল্ডারের সব ফাইল GitHub repository-র root-এ আপলোড করুন (ZIP ফাইলটিকে একা repository-তে দেবেন না)।
৩. GitHub-এর Actions ট্যাবে Build Android APK workflow চালান।
৪. সফল হলে Diniyat-Maktab-APK artifact থেকে app-debug.apk ডাউনলোড করুন।

প্রকল্পটি GitHub Actions-এ Java 17, Gradle 8.9 ও Android SDK 35 ব্যবহার করে।
